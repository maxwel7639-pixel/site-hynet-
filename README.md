# Site Hynet

Next.js (App Router, TypeScript) com CSS Modules. Uma página só.

    npm install
    cp .env.example .env.local   # confirme NEXT_PUBLIC_WHATSAPP
    npm run dev
    npm run build

- Cores e fontes: `src/styles/tokens.css` e `src/app/layout.tsx`
- Dados que faltam (placeholders): `docs/PENDENCIAS.md`
- Variáveis na Vercel: `NEXT_PUBLIC_WHATSAPP` e `NEXT_PUBLIC_SITE_URL`
